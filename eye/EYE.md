# 👁 눈 검사 — 컵·갭 스캐너 결과를 사람 눈으로 추리는 기준

스캐너(숫자 규칙)는 1차 거름망이다. 숫자를 만족해도 사람 눈에 컵/갭이 아닌 종목이 많이 섞인다.
그래서 매일 아침 스캔이 끝난 뒤, 차트를 그림으로 그려 **눈으로 보고** 아닌 것을 뺀다.
원칙: **애매하면 뺀다.** 남는 수가 확 줄어드는 게 정상이다 (컵 수백 → 수십, 갭 천 단위 → 수십).
단, **주도주가 고점 근처에서 쉬는 그릇(엔비디아·주성형)은 모양이 조금 거칠어도 남긴다** — 이걸 빼는 게 가장 큰 실수다.

## ★ 사용자 기준선 (2026-10-06) — 이것부터 맞춘다
- **이게 컵이다: 엔비디아(NVDA), 주성엔지니어링(036930.KQ).** 공통점 = 시장을 이끄는 **주도주(상대강도 85~99)** 가
  **크게 오른 뒤(컵 앞 상승 +50% 이상도 흔함) 고점 근처에서** 한 번 쉬며 그릇을 만들고, 지금 **기준가(왼쪽 고점) 바로 아래·위**에 있다.
  깊이가 깊어도(주성 62%) · 기간이 짧아도 · 오른쪽이 빨리 올라와도, 주도주가 고점 근처에서 버티면 **남긴다 (컵 가능성)**.
  큰 상승 뒤 고점 근처에서 여러 번 흔들린 건 **"두컵"이 아니다** — 가장 최근 그릇(L→B→R)만 보고 판단한다. (10/6 주성을 두컵으로 뺀 건 잘못)
- **이건 컵이 아니다: AGYS, VSXY, HIW.**
  - AGYS — 상대강도 32, 반토막 폭락 뒤 반등, 돌파했다가 기준가 −15%로 다시 무너짐 (약세·돌파실패)
  - HIW — 상대강도 40, 컵 앞이 하락 추세(앞 상승 없음), 돌파 뒤 56일 지나 기준가 아래 (약세·하락중)
  - VSXY — 갭으로 수직 급등한 뒤의 뾰족한 고점에서 짧게(6주) 눌린 것, 기준가 −13% (뾰족고점·덜회복)
- 이 셋 같은 것은 `eye.py render` 가 **숫자로 먼저 자동으로 뺀다** (`자동:` 이유): 상대강도 60 미만(단, 52주 고점 10% 안이면 50까지 봄 — 거대 주도주) · 돌파 10일 넘게 지나 기준가 −5% 아래 ·
  기준가 −12% 아래 · 기준가 +15% 넘게 달려감(늦음) · 컵 앞 60일 상승 20% 미만. 그림에는 이걸 통과한 것만, **상대강도 높은 순**으로 나온다.
- 눈으로 볼 때 질문은 하나: **"주성·엔비디아처럼 강한 종목이 고점 근처에서 쉬는 그릇인가?"** 아니면 뺀다.
  타일 둘째 줄에 `RS(상대강도) · 기준가까지%` 가 적혀 있다.

## 컵 (cup) — 남기는 모양
- 왼쪽에 뚜렷한 고점(L) → **둥글게** 내려갔다가 바닥(B)에서 머물고 → **둥글게** 올라와 왼쪽 고점 근처(R)까지 회복한 **그릇 모양**.
- 컵 앞(왼쪽 60일)에 **올라온 흐름**이 보여야 한다. 컵은 상승 중의 쉬어가기다.
- 손잡이(노란 상자)는 오른쪽 가장자리 근처에서 **살짝** 눌리는 정도. 컵 중간까지 내려오면 손잡이가 아니다.
- 메가터치(446540.KQ, 2026-10-05) 정도의 W자 바닥·조금 느슨한 컵은 **남긴다** — 사용자가 "이건 컵"이라고 한 기준선.

## 컵 — 빼는 모양 (이유 글자 = 그대로 적는다)
| 이유 | 모양 |
|---|---|
| V자 | 급락했다가 바로 급등. 바닥에 머문 시간이 거의 없음 |
| 톱니 | 컵 안이 위아래로 크게 들쭉날쭉, 선이 지저분함 |
| 급등한방 | 오른쪽 회복이 둥근 상승이 아니라 하루이틀 수직 급등 한 방 |
| 하락중 | 왼쪽 고점이 더 큰 하락 추세의 중간 반등. 컵 앞에 상승이 없음 |
| 계단 | 바닥이 없고 계단식으로 내려가기만 함 (오른쪽이 못 올라옴) |
| 횡보 | 깊이가 너무 얕아 그냥 옆으로 기는 박스 |
| 두컵 | 그림 안에 고점이 여럿이라 어느 게 컵인지 모를 만큼 산만함 |
| 늦음 | 돌파(초록 ▲) 뒤 이미 많이 올라 컵 모양보다 급등이 그림을 지배 |
| 뾰족고점 | 왼쪽 고점이 갭·수직 급등으로 찍은 바늘 같은 꼭지 (VSXY). 그 뒤 눌림은 컵이 아니라 급등 되돌림 |
| 약세 | 상대강도가 낮은 종목의 반등 (AGYS·HIW) — 자동 거름이 놓친 경우 |

## 갭 (gap) — 남기는 모양
- 왼쪽에 **평평한 횡보**(회색 상자, 몇 주) → 어느 날 **눈에 띄는 빈칸**(빨간 선 = 갭, 초록 ▲)으로 **뛰어 올라** → 그 뒤로 **박스 위에서 머무름**.
- 갭 크기는 그림에서 "뛰었다"가 보여야 한다(대개 +3~5% 이상).
- 갭 뒤에 조금 눌려도 박스 고점(노란 점선) 위에 있으면 남긴다.

## 갭 — 빼는 모양
| 이유 | 모양 |
|---|---|
| 추세중갭 | 이미 쭉 오르는 중간에 난 갭. 왼쪽에 횡보가 없음 |
| 메움 | 갭 뒤 며칠 안에 박스 안으로 되돌아옴 |
| 안보임 | 갭이 그림에서 티가 안 남 (그냥 하루 양봉) |
| 반등갭 | 박스가 횡보가 아니라 급락 뒤 바닥. 갭이 손실 되돌림일 뿐 |
| 급등후 | 갭 뒤 수직으로 솟아 이미 갭 시가의 한참 위 (추격 자리) |
| 톱니 | 박스가 평평하지 않고 위아래로 크게 출렁임 |
